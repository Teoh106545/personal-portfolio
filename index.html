PROJECT 01

Sarawak Heritage Online Auction (SHAA) Database System

Design relational database schema and a database application for the Sarawak Heritage Online Auction (SHAA).

HTML Database Concept

Project Overview

The Sarawak Heritage Online Auction (SHAA) is a database application designed to manage online auctions for Sarawak heritage items. The system stores and manages information about registered users, auction items, bids, orders, payments, and deliveries. It also provides reports on user activities, auction items, completed orders, and the top five most popular auction items. The project focuses on designing a well-structured relational database using ER modelling, normalization, and SQL queries to ensure efficient data management and retrieval.

My Contribution

Technologies Used

MySQL and XAMPP

What I Learned

Through this project, I learned how to design and implement a relational database based on real-world requirements. I gained practical experience in creating ER diagrams, defining primary and foreign keys, and applying 1NF, 2NF, and 3NF normalization to reduce data redundancy and prevent database anomalies. Besides that, I also improved my SQL skills in inserting, updating, deleting, and retrieving records as well as generating reports using aggregate functions, joins, grouping, and sorting.

PROJECT 05

Simulation of A CPU Scheduler

Develop a simulation (using Python, C++, or Java) of a CPU scheduler using the Round Robin (RR) algorithm. The simulation must precisely model the execution of processes and the overhead incurred by context switching.

C++

Project Overview

This project involves developing a CPU scheduling simulator using the Round Robin algorithm to demonstrate how an operating system manages process execution. The simulation generates 100 synthetic processes with random arrival times and CPU burst times to evaluate the performance of three different time quantum values such as 3 ms, 10 ms, and 25 ms. It also incorporates a 1.0 ms context-switching overhead to simulate the additional time required when switching between processes. The project aims to compare scheduling performance using average waiting time, average turnaround time, and total context-switching overhead.

My Contribution

I worked on developing the Round Robin (RR) CPU scheduling simulation code and recording the output data.

Technologies Used

Python and Round Robin (RR) Algorithm

What I Learned

Through this project, I learned how the Round Robin scheduling algorithm allocates CPU time among multiple processes and how time quantum selection affects scheduling performance. I gained practical experience in simulating process execution, managing a ready queue, tracking global simulation time, and accounting for context-switching overhead. I also improved my understanding of finish time, turnaround time, and waiting time calculations.
